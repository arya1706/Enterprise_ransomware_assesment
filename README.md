# Enterprise_ransomware_assesment

This project evaluates hypothetical ransomware risks for a fictional organization using Python and the NIST Cybersecurity Framework (CSF) 2.0. It calculates risk scores based on likelihood and impact, classifies risks as Low, Moderate, High, or Critical, visualizes the results using charts, and recommends security measures for prevention, detection, response, and recovery.

Technologies Used: Python, Jupyter Notebook, Pandas, Matplotlib.

Dataset: A synthetic dataset of hypothetical ransomware risks created within the notebook. No real company data is used.

Purpose: To demonstrate cybersecurity risk assessment, risk prioritization, and mitigation planning.
